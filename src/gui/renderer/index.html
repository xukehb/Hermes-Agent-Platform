权限与安全策略

控制智能体在执行任务时的自动化权限级别与授权模式

完完全全放开权限
全自主极速执行！自动允许文件读写、执行终端 Shell、调用所有 MCP 插件与子智能体，零阻断弹窗。
推荐开发者使用
敏感写操作确认
读取文件和代码分析自动执行，修改本地磁盘文件或执行终端危险命令前进行弹窗确认。
平衡模式
严格单步确认
最严格安全模式。智能体的每一个工具调用、网络请求和命令执行均需人工逐项审核授权。
高安全要求

细粒度权限开关

系统终端 Shell 命令执行 (allowShell) 允许智能体在工作区运行 build, test, git, npm 等终端命令
工作区文件磁盘写入与修改 (allowFsWrite) 允许智能体创建、修改与应用代码 Patch 到本地文件
网络请求与外网数据抓取 (allowNetwork) 允许智能体发起 HTTP 请求抓取远程 API 与文档数据
多智能体分工与子 Agent 编排 (allowSpawnSubagent) 允许主智能体派发并调度子智能体并发执行专项子任务
