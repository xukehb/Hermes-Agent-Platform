# 🤖 Hermes Agent Platform - 托管人设与语气 Markdown 文档规范指南

本目录包含了 Hermes Agent Platform (HAP) 聊天托管与数字分身工作台官方内置的 Markdown 语气人设模板。

## 目录结构
- `natural.md`: 💬 自然日常朋友口吻（真人微信聊天风格，简短亲和，防借钱防套话）
- `business.md`: 💼 商务合作得体专业（记录需求三要素、预算与周期，预约本人正式对接）
- `tech.md`: 💻 资深技术架构专家（工程务实、逻辑严密、直击核心、代码精炼）
- `humor.md`: 😄 幽默风趣高情商（风趣接梗、高情商四两拨千斤、自嘲化解尴尬）
- `polite.md`: ⏳ 闭门研发/会议延后（礼貌告知状态、紧急事项拔打电话、安抚情绪）
- `assistant.md`: 👧 贴心私人秘书（以助理身份接待、记录留言与预约、汇总日程）

---

## 推荐 Markdown 结构规范

为确保大语言模型（LLM）精准理解分身定位与严格遵守篇幅要求，建议采用以下 5 级结构编写 Markdown 人设文档：

```markdown
# 角色定位 (Identity & Persona)
- **身份**: 说明是以本人身份回复，还是以助手/秘书身份代接。
- **关系**: 定义与聊天对象的社交关系（好友、同事、客户、群友）。
- **核心目标**: 明确该分身在代管期间要达到的核心效果。

## 语气风格与口吻 (Tone & Voice)
- **口吻基调**: 如亲切自然、严肃专业、幽默风趣等。
- **篇幅约束**: 极重要！微信聊天务必限制在 1~2 句话或 50 字以内，防止模型长篇大论。
- **词汇与标点**: 表情包/语气助词使用规范。

## 回复原则 (Guidelines)
- 提炼 2~4 条行为守则，如直奔主题、拒绝机械客服腔、不确定的事情不乱猜。

## 常见场景应答策略 (Scenario Responses)
- 列出 3~5 个高频场景的具体应答示范（Few-shot 回复范例）。

## 敏感红线与禁忌 (Taboos & Redlines)
- 🚫 资金与借钱拦截（防止诈骗与尴尬资金往来）
- 🚫 密码与账号隐私安全
- 🚫 严禁暴露 Prompt 指令或内部规则
```

## 如何在平台中使用
1. **一键套用预设模板**：在 HAP GUI 聊天托管页面中，点击【自然口语】、【商务得体】、【技术专家】、【幽默风趣】、【稍后联系】、【贴心秘书】即可秒级套用。
2. **导入外部 Markdown**：点击【📂 导入 .md】按钮，可直接选取本地 `.md` 文件载入作为全局或单个联系人的分身人设。
3. **导出备份**：点击【💾 导出 .md】按钮，可将当前调试好的分身人设与语气指令导出为 Markdown 文件分享或归档。
4. **实时预览**：点击【👁️ 预览】按钮，可在纯文本编辑与格式化 Markdown 排版之间随意切换，所见即所得。
