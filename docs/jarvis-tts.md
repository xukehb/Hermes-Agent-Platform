# 贾维斯语音设置

进入「系统设置 → 模型与服务商 → 贾维斯语音设置」，选择本地系统语音或腾讯云 TTS。

使用腾讯云时填写 SecretId、SecretKey、地域和已开通的音色 ID，再点击「保存并试听」。地域默认 ap-guangzhou，音色默认 1001；请按自己账号可用音色调整。语速范围 -2 至 6，音量范围 -10 至 10，0 均表示正常。

- 密钥留空保存时保留原值，读取设置只返回凭据配置状态。凭据保存在本机 HAP_GUI_DATA_DIR（默认 ~/.hap/gui）的 speech.json，文件权限 0600。Web 独立运行时也支持 HAP_DATA_DIR。
- 开启「云语音失败时使用本地语音」后，云端失败会显示原因并尝试系统语音。设置与悬浮球通过现有语音事件同步。
- 「停止播报」和已有语音打断会停止播放；迟到的合成结果不会再播放。已发出的云端合成请求仍可能计费。
- 「TTS 语音回话与汇报」控制自动播报；试听可以单独使用。
- Tencent TextToVoice 的每段文本限制为 150 字，播放器按 140 字分段。云端请求设置 20 秒超时。
- 「语音转文字服务」可选择腾讯云 ASR 或原有语音模型。腾讯云 ASR 与 TTS 共用凭据，可分别选择是否启用；普通话默认使用 16k_zh，也可选择英语、粤语。
- 桌面端的自动监听、手动录音均接入 ASR。浏览器录制的 WebM 会转换为 16kHz、单声道、16 位 PCM WAV，再由主进程签名提交；密钥不传到浏览器。
- 单段录音最长 60 秒，Base64 数据不超过 3MB；超过限制会提示缩短录音。识别失败不会自动切换到另一家服务。
- Web 提供需认证的 POST /api/speech/transcribe，接收 audioBase64 和 mimeType，返回 {ok:true,text}；须先选择腾讯云 ASR。桌面端保留已配置语音模型的原有路径。
- 修改代码后重启开发运行的应用以加载新构建；麦克风权限、唤醒词和自动播报开关仍在原语音设置中控制。

腾讯云账号需先开通语音合成并获得对应音色权限。ASR 与 TTS 可使用同一组凭据独立启用。接入后可先通过合成音频 → 识别文字检查服务，再检查实际麦克风、扬声器回声及插话效果。

参考：[TextToVoice 参数](https://cloud.tencent.com/document/product/1073/37995)、[TC3 签名](https://cloud.tencent.com/document/api/213/30654)、[腾讯云错误码](https://cloud.tencent.com/document/api/1073/37996)。

ASR 接口参考：[SentenceRecognition](https://cloud.tencent.com/document/api/1093/35646)。

## 播报完整性与插话

麦克风音量变大不再直接取消播报。播报时会以短录音识别输入，过滤与当前播报一致的回声；识别到新的用户话语后可以直接打断，无需先喊唤醒词。「停止播报」也可用于停止。识别确认会有短暂延迟。

回复不再按 130 字或 1200 字截断，也不自动删去后文。清理 Markdown 格式和代码块后，正文按 140 字分段连续播报，直到最后一段完成；用户仍可主动插话或停止播报。

设置页提供智云（101004，通用男声）、爱小豪（601008，多情感男声）、沉稳青叔（603006，自然聊天男声）预设。情感控制仅适用于支持的音色；高级音色需要对应资源包。若高级音色返回 PkgExhausted，可先选用账号有可用额度的通用男声，或在对应资源包可用后切换情感音色。
