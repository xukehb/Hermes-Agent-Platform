# Hermes Agent Platform v0.1.3 Multi-platform Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and publish Hermes Agent Platform v0.1.3 installers for Windows, Ubuntu, and macOS.

**Architecture:** `package.json` is the single source of truth for version, product identity, and electron-builder targets. A tag-triggered GitHub Actions matrix builds native installers on each operating system, transfers them as workflow artifacts, and creates one GitHub Release after every build succeeds.

**Tech Stack:** Electron 37, TypeScript, Vitest, electron-builder 26.15.3, GitHub Actions, GitHub Releases

---

## File Structure

- Modify `tests/package-scripts.test.ts`: enforce release metadata and package target contracts.
- Modify `package.json`: set version/product identity, add reproducible platform scripts, and configure installer targets.
- Modify `package-lock.json`: lock application version and electron-builder dependency.
- Create `.github/workflows/release.yml`: test, native matrix build, and release orchestration.
- Modify `README.md`: document v0.1.3 package commands, outputs, and unsigned-package limitations.
- Update `.codex/testing.md`, `.codex/review-report.md`, `.codex/operations-log.md`, and `verification.md`: record local verification and final review evidence.
